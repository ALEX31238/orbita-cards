# Орбита — веб-версия

Карточки по физике для телефона: та же колода и то же расписание повторений, что и в приложении «Орбита» для Mac.

- `deck.json` выгружается из Mac-версии: `Orbita --export-deck Web/deck.json`
- Формулы рисует KaTeX, файлы лежат рядом (`vendor/katex`) — интернет нужен только при первом открытии
- Прогресс хранится в самом телефоне (localStorage)
- `sw.js` кладёт всё в кэш, поэтому страница работает без сети (в метро тоже)

## Локально

```bash
python3 -m http.server 8765 --directory Web
```

Открыть http://localhost:8765 (на localhost кэш намеренно отключён).
